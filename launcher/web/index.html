常用命令

在项目根目录下执行。

python run.py启动 Bridge（默认读取 .env 配置）
python run.py --check-config校验配置并退出，不打印明文密钥
python tests/test_core.py运行核心逻辑测试

管理台进程

如果页面卡死或需要重启管理台，可以安全退出当前管理台；重启后 Bot 需要重新启动。
